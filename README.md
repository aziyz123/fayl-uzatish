# Fayl Uzatish

Telefondan kompyuterga fayl uzatish ilovasi (WebRTC + Firebase Realtime Database).

## Ishlatish

1. `fayl-uzatish.html` ni brauzerda oching (yoki GitHub Pages orqali).
2. Kompyuterda **Xona ochish** tugmasini bosing.
3. Telefonda QR kodni skanerlang yoki xona kodini kiriting.
4. Fayl tanlang va yuboring.

- To'g'ridan-to'g'ri (P2P): 200 MB gacha
- Zaxira (Firebase): 60 MB gacha

## Fayllar

- `fayl-uzatish.html` — asosiy sahifa
- `fayl-core.js` — uzatish mexanizmi (WebRTC + relay)
- `fayl-ui.js` — interfeys va Firebase sozlamalari
